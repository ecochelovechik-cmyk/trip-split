# Кто кому должен

Дележка расходов в совместной поездке: несколько человек с разных телефонов вносят траты
в одну общую базу, приложение считает, кто кому сколько отдаёт — минимальным числом переводов.

Открывается двумя способами по одному адресу: обычной ссылкой в браузере (без регистрации)
и как Telegram Mini App.

- Приложение: `https://ecochelovechik-cmyk.github.io/trip-split/`
- Бэкенд: Cloudflare Worker + база D1
- Развернуть с нуля: [DEPLOY.md](DEPLOY.md)
- Контракт и правила разработки: [SPEC.md](SPEC.md)

## Как это устроено

Состояние поездки не пересылается целиком. Телефон отправляет **операции** («добавил трату»),
сервер присваивает каждой номер, остальные телефоны докачивают только новые и складывают
из них состояние. Так одновременная запись с пяти телефонов ничего не затирает, а офлайн-очередь
досылается без дублей.

Ссылка на поездку **и есть ключ доступа** — кто получил ссылку, тот может вносить траты.
Отдельных паролей нет (то же решение, что в калькуляторе себестоимости).

## Файлы

| файл | зачем |
|---|---|
| `docs/index.html` | разметка и стили |
| `docs/app.js` | логика: операции, расчёты, синхронизация, экраны |
| `docs/i18n.js` | строки RU / UZ / EN |
| `docs/config.js` | адрес Worker — вписывается после развёртывания |
| `docs/sw.js` | офлайн-кэш; **версию кэша поднимать при каждом обновлении** |
| `worker/worker.js` | API: поездки, операции, лимиты |
| `worker/telegram.js` | бот: итоги по команде, вечерняя сводка, проверка подписи Mini App |
| `worker/schema.sql` | схема базы |
| `dev/dev-server.js` | локальная копия API на `node:sqlite` — тесты без Cloudflare |
| `dev/test-api.mjs` | автотесты API |

## Как обновлять

1. Правки в `docs/` или `worker/`.
2. **Поднять версию кэша в `docs/sw.js`** — иначе у людей останется старая копия из офлайн-кэша.
3. Коммит и push в `main` — GitHub Pages подхватывает фронт сам.
4. Изменения в `worker/` — вставить новый код Worker в веб-кабинете Cloudflare (шаги в DEPLOY.md).

## Проверка перед выкладкой

```
node dev/test-api.mjs
```

Тесты обязаны проходить целиком. Отдельно проверяется арифметика: сумма долей равна сумме трат
до копейки, сумма всех балансов — ноль, трата 10.00 на троих даёт доли 334 / 333 / 333.

## Что здесь нельзя делать

- Класть токены и ключи в файлы репозитория — только переменные окружения Cloudflare.
- Сливать записи по совпадению названия: добавление — всегда добавление
  (на этом однажды потерялись 25 расчётов в калькуляторе).
- Глушить ошибки записи молча — их видит человек.
